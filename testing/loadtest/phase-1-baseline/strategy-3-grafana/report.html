🔴 Xác nhận độ trễ tích lũy địa lý (Geographic Latency Accumulation)

Khi phát tải từ hạ tầng Grafana Cloud (đặt tại Ohio, Mỹ - load_zone: amazon:us:columbus) hướng về Server Render (Singapore) và ghi Database (Nhật Bản), độ trễ tích lũy tăng cao rõ rệt:
• Chat Delivery Latency: p95 đạt khoảng **1.75 - 1.85 giây (1750ms - 1850ms)**.
• HTTP Request Duration: Trung bình khoảng **1.30 - 1.45 giây (1300ms - 1450ms)**.
Điều này chứng minh việc mạng lưới đi qua nhiều chặng lục địa (Mỹ -> Singapore -> Nhật Bản -> Singapore -> Mỹ) cộng thêm việc xếp hàng DB Connection Pool làm độ trễ bị đẩy lên cực hạn.
